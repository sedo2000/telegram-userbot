# Telegram Userbot

مشروع Userbot لحساب Telegram باستخدام Node.js وGramJS.

## الملفات
- `index.js`: تشغيل البوت والأوامر والجدولة.
- `get_session.js`: إنشاء جلسة Telegram StringSession.
- `Dockerfile`: بيئة تشغيل تتضمن yt-dlp وFFmpeg.
- `.env.example`: قالب متغيرات البيئة.

## الإعداد
1. انسخ `.env.example` إلى ملف `.env` على جهازك.
2. املأ `API_ID` و`API_HASH` من https://my.telegram.org.
3. نفّذ `npm install`.
4. شغّل `npm run session` واتبع خطوات تسجيل الدخول، ثم انسخ قيمة الجلسة إلى `SESSION_STRING`.
5. شغّل `npm start`.

على الاستضافة، أضف المتغيرات نفسها في إعدادات Environment Variables ولا ترفع ملف `.env` أو قيمة الجلسة إلى GitHub.

## الأوامر
- `.اوامر` عرض الأوامر
- `.ترحيب نص` تغيير رسالة الترحيب
- `.تفعيل` تبديل تشغيل الترحيب
- `.استثناء ID` إضافة استثناء
- `.حذف_استثناء ID` حذف استثناء
- `.المستثناة` عرض الاستثناءات
- `.جدولة نص` إرسال النص كل خمس دقائق إلى المحادثة المحددة في `SCHEDULE_CHAT_ID`
- `.الجدولة` عرض الحالة
- `.إيقاف_الجدولة` إيقاف الإرسال المجدول
- `.ذكاء تشغيل` أو `.ذكاء إيقاف` تفعيل/إيقاف الرد الذكي الخاص (يتطلب GEMINI_API_KEY)
- `.mp3 URL` محاولة استخراج الصوت من رابط مدعوم بواسطة yt-dlp

## تنبيهات
- الجدولة مقيدة بمحادثة واحدة فقط عبر `SCHEDULE_CHAT_ID`؛ لا تضع معرف مجموعة لا تملك صلاحية النشر فيها.
- لا تستخدم الأوامر لإرسال رسائل مزعجة أو مخالفة لشروط Telegram.
- StringSession تمنح وصولاً إلى حسابك؛ تعامل معها ككلمة مرور ولا تشاركها.
- لم يتم اختبار هذا المشروع على حسابك أو منصة استضافة بعد. الاستضافة المجانية قد توقف الخدمات الخاملة، لذلك لا يوجد ضمان تشغيل دائم.
- تنزيل القصص/Stories غير مضمّن في هذه النسخة؛ لا تعتبره ميزة جاهزة.
